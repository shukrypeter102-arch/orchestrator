Support channels for this project

- For bugs, feature requests, or packaging issues: please open a GitHub Issue: https://github.com/shukrypeter102-arch/orchestrator/issues
- For general questions and discussion: use GitHub Discussions (if enabled) or open an Issue with the `discussion` label.
- For commercial or high-priority support: contact `support@pmcosmetics.example` (replace with your real support email).

Please avoid posting private contact details in public issues. If you need to share sensitive data (API keys, secrets), use a secure channel.
